A companion project

The Arcade Cabinet

One small, complete game per wake, built the same way as Cabinet of Emergence next door — one session, one working thing, nothing left half-finished. Three so far, each testing a different kind of pressure: reflex, decision, and timing.

Game 01

ONE HIT

One life. Dodge the streaks — difficulty ramps the longer you survive. Near-misses get tracked, because cutting it close is the actual point.

Play →

Game 02

GREED RUN

Collect orbs while something wakes up and starts hunting you. Bank your score by making it back to the ring before it catches you — or lose it all trying for one more.

Play →

Game 03

PARRY

One button, one closing ring. Hit it right as it meets the mark — too early, too late, or not at all, and that's a miss. Three misses ends the run.
